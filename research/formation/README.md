# Formation ads — sources à lire

Dépose ici tout ce qui doit « former » Claude sur les ads : PDF, captures d'écran, notes, exports
de résultats (CPM, taux de clic, coût par achat, ROAS), structures de campagne.

Claude lit ce dossier, confronte chaque source aux données concurrentes déjà relevées
(`research/top100-creas.json`, `research/angles-concurrents.md`) et en tire les règles dans
`research/playbook-ads.md`, relu à chaque session.

Limite d'envoi par le site GitHub : 25 Mo par fichier. Les vidéos de formation ne passent pas
par ici (voir la conversation du 6 nov.).
