## Comment reprendre le travail

Ouvre une session Claude Code sur ce dossier — depuis [claude.ai/code](https://claude.ai/code), l'app mobile, ou n'importe quelle machine.
`CLAUDE.md` se charge automatiquement : contexte complet, grille de décision, produits déjà écartés, prochaine action.

| Dossier | Contenu |
